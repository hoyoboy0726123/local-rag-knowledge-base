# EVT 階段作業規範

## 階段目標
驗證設計的功能完整性，確認各項規格可達成。

## 必要產出物
1. EVT 測試計畫（需於階段開始前一週完成核准）
2. 功能測試報告
3. 電性量測報告
4. 問題追蹤清單（Issue List）
5. EVT 檢討會議記錄

## 測試項目
### 基本功能測試
- 開關機測試 500 次
- 各介面功能驗證（USB、HDMI、網路、音訊）
- BIOS 設定項目完整性

### 電性測試
- 電源時序量測
- 各電壓軌漣波量測
- 待機功耗與滿載功耗

### 初步熱測試
- 室溫滿載溫度分布
- 風扇轉速與噪音初測

## 進入下一階段的條件
- 所有 P1 等級問題已關閉
- P2 等級問題已有明確對策與時程
- 功能測試通過率達 95% 以上
